# User Settings Interface

## Project Overview
This project displays a Python function named `set_user_setting` and its docstring within an HTML page. The interface demonstrates heading and title customization using HTML and CSS.

## Features
- **Custom Page Title:** Displays "User Settings Interface" in the browser tab.
- **Styled Heading:** Uses a dark blue color, bold text, larger font size, and center alignment.
- **Python Code Display:** Shows the `set_user_setting` function and its docstring.
- **Clean Layout:** Uses a peach background with a white code section.
- **Readable Code:** Uses a monospace font for displaying Python code.

## Technologies Used
- HTML5
- CSS3
- Python (displayed as code in the HTML page)

## Project Structure

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. View the customized heading and displayed Python docstring.
